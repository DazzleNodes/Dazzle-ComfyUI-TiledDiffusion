# Human Test Checklist: seam-bias knob + the full-denoise coherence gate

**Target version:** v0.2.3
**Ships with commit:** TBD (seam_bias_y / seam_bias_x widgets + this gate)
**Companion automated tests:** 7 tests in `tests/test_gaussian_weights.py` (incl. bias=0 identity pin and bias=0.5-y == pre-fix-blend pin), plus the suites run by `python tests/verify_install.py`

## What this is

Two things. First, verification for the experimental `seam_bias_y` / `seam_bias_x` widgets (a deliberate, dosed re-introduction of the pre-#5 blend asymmetry as a coherence tie-breaker for full-denoise tiled generation; default 0.0 = the mathematically-correct weights, byte-identical, pinned by test). Second — and permanently — **the coherence gate**: the render matrix that MUST be run whenever Mixture-of-Diffusers blend weights change, because unit pins guarantee weight shapes, not render outcomes. This gate exists because the #5 weights fix, verified only on partial-denoise hires, silently collapsed full-denoise reference renders into tile collages (discovered 2026-07-04 via an exact-config rerun against an archived render).
