# Human Test Checklist: Flux.2 packed-latent fixes (tile-size semantics + reference resample)

**Target version:** v0.2.0 (versioning established with this release; see pyproject.toml + CHANGELOG.md)
**Ships with commit:** TBD (working tree on top of `6caf25e`) — two commits planned: `fix(node): derive tile compression from model latent_format` and `fix(ref-latents): packed-aware resample for Flux.2 2x2-packed latents`
**Companion automated tests:** 5 tests in `tests/test_flux2_packed_resample.py` (pack/unpack roundtrip; fixed-path equivalence; legacy comb regression >= 5x; non-packed byte-identity; pack-layout position probe) — all passing at authoring time. Plus `tests/one-offs/test_resample_ref_to_canvas.py` (aspect guard, warn dedup, 4D/5D) and `tests/one-offs/flux2_packed_resample_probe.py` (measurement probe).

## What this is

Two fixes change how the TiledDiffusion node handles Flux.2's packed latent format (`[B,128,H/16,W/16]`, a 2x2 pixel-shuffle of a 32ch/8x VAE latent):

1. **Tile compression from the model** — widget-px -> latent-cell conversion reads `latent_format.spacial_downscale_ratio` instead of assuming 8. **User-visible semantics change on Flux.2:** a "512" tile was physically 1024px before, true 512px now; overlap semantics change identically. Also affects ChromaRadiance (1 px/cell) and video formats (16/32) if used.
2. **Packed-aware reference resample** — non-canvas reference latents on Flux.2 are unpacked to the 32ch/8x grid, bilinearly resampled, and repacked (the old path interpolated packed planes independently -> high-frequency comb corruption). `TD_FLUX2_PACKED_RESAMPLE=0` restores the legacy path for A/B.

This checklist covers what the automated tests cannot: exact console strings (quoted verbatim in a GitHub reply as a stale-file guard), real tile-grid counts, GPU render behavior, and default-path non-regression. Steps marked **PROGRAMMATIC** can be run by a test agent; steps marked **MANUAL** need a human (GPU renders + image judgment).
